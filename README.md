# Surge 机场流量信息

一个用于 Surge iOS 的订阅流量信息模块。填写订阅链接，即可在面板中查看流量用量、重置倒计时和套餐到期时间。

**最多支持 5 个订阅，每个订阅一个独立面板；不用的位置不显示空面板。**

## 功能

- 显示已用流量与总流量，已用流量为上传和下载之和。
- 自定义每个订阅的显示名称。
- 手动设置每月重置日，显示距离下次重置的剩余天数。
- 支持将重置时间标记为「长期有效」。
- 从订阅响应中读取套餐到期时间，月份和日期统一显示两位数字。
- 在面板标题中显示最后一次成功获取信息的时间。
- 获取失败时保留该订阅上次成功的面板内容；没有成功记录时显示错误提示。
- 直接填写原始订阅链接，无需 URL Encode。

显示示例（仅展示格式，非真实套餐数据）：

```text
我的机场 | 10-21 12:30
用量：12.34 GB | 50.00 GB
重置时间：剩余21天
到期时间：2026 年 11 月 09 日
```

## 安装

**需要 Surge iOS 5.11.0 或更新版本，并具备信息面板使用权限。**

1. 打开 Surge → **Modules（模块）→ Install New Module…（安装新模块）**。
2. 粘贴下面的模块地址并安装。
3. 打开模块的 **Edit Arguments（编辑参数）**，填写需要使用的订阅。
4. 保存并启用模块，返回面板点击刷新。

```text
https://raw.githubusercontent.com/Eightean/Surge/main/Sub-info.sgmodule
```

安装的是 `.sgmodule` 模块，不是 `.js` 脚本。若之前使用过同类本地模块，请停用旧模块，避免重复显示。

## 参数填写

每组订阅包含三项，订阅 1 至订阅 5 的填写方式相同：

| 参数 | 填写说明 |
| --- | --- |
| 订阅 1 名称 | 面板显示的名称，例如「我的机场」，也可保留默认名称 |
| 订阅 1 链接 | 机场提供的完整订阅链接，直接粘贴，不编码、不加引号 |
| 订阅 1 重置日 | 可选，填写每月 `1–31`、`长期`、`长期有效`，或保留 `-` |

**只用一个订阅，就只填写一组；其他组的链接保留 `-`。** 可以任意选择位置，不必连续填写。链接保留 `-` 的组不会启用对应面板。

填写时请注意：

- 名称和链接不要包含英文逗号、英文单引号、英文双引号或换行。
- 名称不要包含 `&`。
- 重置日不填时请保留 `-`；这只会隐藏重置信息，不影响流量和到期信息。

### 重置时间

| 重置日填写内容 | 显示结果 |
| --- | --- |
| `1–31`，例如 `9` 或 `09` | `重置时间：剩余N天` |
| `长期` 或 `长期有效` | `重置时间：长期有效` |
| `-` | 不显示重置信息 |

重置日需要根据自己的套餐手动填写，不会从到期日期推算。

- **重置当天按本次已重置计算**，直接显示到下个月重置日的剩余天数。
- 按实际日历计算，不固定为 30 天或 31 天。
- 如果某个月没有所填日期，则按该月最后一天计算。

倒计时使用设备本地日期，仅用于提示；它不查询机场的实际重置状态，也不精确到具体时刻。填写「长期」只是显示标记，不会改变套餐规则。

### 到期时间

到期信息来自订阅响应头中的 `expire` 字段，无需手动填写：

| 机场返回的信息 | 显示结果 |
| --- | --- |
| 有效到期时间戳 | `到期时间：2026 年 08 月 09 日` |
| `expire=` 为空或为 `0` | `到期时间：长期有效` |
| 没有提供到期字段 | `到期时间：未提供` |
| 到期值无效 | `到期时间：未知` |

空值或零按无到期限制处理，不同机场的约定可能不同，**实际有效期以机场套餐说明为准**。长期有效不代表流量无限，也不代表服务永久运营。

## 更新

模块和远程脚本的更新是分开的，面板显示结果也会缓存。

1. 在模块列表更新「机场流量信息」。
2. 返回面板，点击刷新按钮。
3. 如果仍显示旧内容，进入 Surge 的 **External Resources（外部资源）**，手动更新 `Sub-info-panel.js`，然后再次刷新面板。

面板和脚本的更新间隔均为 `86400` 秒，实际检查时机由 Surge 决定，并非后台每隔一天必定执行。面板刷新按钮会重新运行脚本，但不一定重新下载 JS。

模块中的脚本地址带有 `?v=…` 版本号，用于区分更新后的资源。若更新仍提示「已经最新」，也可能是 GitHub 下载缓存尚未刷新，可稍后再试，无需卸载重装 Surge。

更新通常不需要重填参数；从早期版本迁移时，如果参数名称发生过变化，请重新核对填写内容。

## 🔒 隐私提示

**订阅链接由 Surge 保存在本地。本模块不会将链接上传到 GitHub 或其他地方用于收集。**

查询流量时，脚本会请求您填写的订阅地址；这是获取套餐信息所必需的网络请求。Surge 自身的 iCloud 同步、配置导出或系统备份不受本模块控制，因此不承诺链接仅留在本机。

**请勿公开包含私人订阅链接的截图、配置或备份，也不要将真实链接提交到公开仓库。** 如果链接泄露，请到机场后台重置。

## 常见问题

**为什么显示「订阅未提供流量信息」？**  
当前脚本使用 HEAD 请求读取 `subscription-userinfo` 响应头。机场未提供该响应头，或不支持相应请求时，无法读取流量。

**为什么有面板但显示获取失败？**  
填写链接并不保证订阅可用。请检查网络、链接是否过期，以及机场服务是否正常。如果该订阅已有成功记录，获取失败时会保留上次的完整结果（包括成功时的时间与倒计时），而不是刷新成错误提示；没有成功记录时才显示错误。更换订阅链接或显示名称后不会复用旧记录。成功结果通过 Surge 的持久化存储保存；卸载、清理数据或其他设备上不保证有历史记录。

**能自定义图标吗？**  
当前参数表未开放图标和颜色设置，默认使用蓝色 SF Symbol 图标。信息面板不是策略组图标，不能直接套用策略组的图片链接。

## 文件

| 文件 | 用途 |
| --- | --- |
| [Sub-info.sgmodule](Sub-info.sgmodule) | 当前模块的安装入口，包含五组订阅参数及面板配置 |
| [Sub-info-panel.js](Sub-info-panel.js) | 当前模块使用的独立面板脚本 |

`Sub-info.js` 是兼容旧配置的单订阅脚本，现已同步支持重置倒计时、长期有效、两位月份/日期及失败保留上次结果；仍支持旧参数 `title`、`icon`、`color`、`method` 和 `expire`（日期或时间戳；`false` 隐藏到期行）。原始订阅链接应放在 `&url=` 后、参数末尾；旧版完整 URL Encode 链接也可使用。当前模块继续使用 `Sub-info-panel.js`，无需改动模块配置。`Sub-info-optional.js` 是保留的早期合并面板脚本，当前模块不引用。
